# وضعیت پیاده‌سازی و حدود تحویل

نسخهٔ 0.1 مسیر متنی نسخهٔ اول را اجرا می‌کند. نمونه‌های قرارداد در سند اصلی عیناً به‌عنوان کد ناقص کپی نشده‌اند؛ `implementation_pending` یا TODO اجرایی در مسیرهای فعال وجود ندارد. این سند از ادعای تکمیل تمام فازهای نقشهٔ راه یا تأیید Production جلوگیری می‌کند.

| بخش سند | پیاده‌سازی فعلی | مرز آزمون / ادامهٔ نقشهٔ راه |
|---|---|---|
| ساختار و دامنه | TypeScript strict، Nest/Fastify، Next، ماژول‌های مستقل و Port مدل/کانال، public-api، تست مرزهای Domain/Application | Repositoryها SQL تراکنشی را نگه می‌دارند؛ ساختار برای MVP عمداً کم‌تعداد است. |
| چندحسابی | Worker مشترک با سقف ۱۰ نشست، lease ۴۵ثانیه، تمدید دوره‌ای، fencing در Auth و Send، شکست مستقل | اتصال زنده و قطع واقعی چند شماره نیازمند شمارهٔ آزمایشی است. |
| نشست | store دیتابیس رمزگذاری‌شده، persistence اتمیک Signal Key، بازیابی پیام برای Retry، QR رمزگذاری‌شده | Baileys 7.0.0-rc14 قفل است؛ RC بودن و آزمون زنده در Staging باید در انتشار لحاظ شود. |
| پیام | متن، notify/append/history، self-message، freshness، dedupe مرکب، Outbox پایدار، recovery صف | رسانه، صوت، گروه و Newsletter فعال نیستند؛ در سند برای فاز بعدی‌اند. |
| هویت | PN/LID و suffix دستگاه، ادغام نمای صندوق با حفظ رکوردهای اصلی و history نگاشت | برگشت نگاشت ابزار اپراتوری آماده ندارد؛ رکورد اصلی و merge history برای بررسی/بازگردانی مدیریتی محفوظ است. |
| ارسال و دخالت انسان | چهار حالت، نسخهٔ خوش‌بینانه، recheck در لحظه ارسال، manual idempotency، draft انسانی، UNKNOWN بدون retry کور | تغییر حالت نمی‌تواند پیامی را که قبلاً در شبکه ارسال شده پس بگیرد؛ این محدودیت بیرونی است. |
| AI | OpenAI و adapter محلی سازگار، نسخهٔ prompt/model/تعرفه، context محدود، debounce، ثبت خطا/هزینه، شبیه‌ساز | Claude، fallback خودکار، خلاصه‌سازی بلندمدت و ابزارهای نوشتنی در نسخهٔ فعلی فعال نیستند. سرویس محلی باید جدا نصب شود. |
| دانش | متن و FAQ حساب‌محور با PostgreSQL FTS | آپلود PDF، استخراج رسانه و pgvector مرحلهٔ بعدی‌اند. |
| گزارش | Facts پیام به‌صورت تکرارپذیر؛ بازهٔ نیمه‌باز، timezone، نمونهٔ P50/P95، هزینه، مقایسه، CSV/XLSX | تقویم کاری SLA، attribution فروش، Lead واقعی، طبقه‌بندی intent، زمان‌بندی ارسال گزارش و warehouse پیشرفته پیاده نشده‌اند. دادهٔ ناموجود جعل نمی‌شود. |
| دسترسی | نقش‌ها، مجوز حساب در Query، Session+CSRF، MFA، API token فقط خواندن حساب/گزارش، audit | MFA در تولید برای نقش حساس الزامی است؛ OAuth/SSO در دامنهٔ این نسخه نیست. |
| پنل | فارسی RTL، responsive، inbox صفحه‌بندی‌شده و محدود، مدیریت حساب/ایجنت/کاربر/دانش/گزارش | ترجمهٔ کامل انگلیسی و virtual scrolling برای هزاران ردیف مرحلهٔ تکمیل UI است؛ درخواست فعلی هر بار حداکثر ۱۰۰ ردیف می‌خواند. |
| یکپارچه‌سازی | صفحه و قرارداد غیرفعال | طبق پاسخ صریح کاربر CRM/SMS به سرویس واقعی متصل نیستند؛ Tool Runner، Webhook delivery و mapping اختصاصی هنگام انتخاب سرویس تکمیل می‌شوند. |
| عملیات | Docker non-root، Compose خصوصی، Caddy، لاگ redacted، health/queue/worker monitoring، backup رمزگذاری‌شده با HMAC، CI | OpenTelemetry collector، هشدار بیرونی، PITR و اهداف رسمی RPO/RTO به زیرساخت استقرار نیاز دارند؛ هنوز تأیید عملیاتی نشده‌اند. |

اتصال واقعی Baileys، اعتبار کلید OpenAI، اسکن QR، تحویل به شمارهٔ واقعی و بنچمارک بار هدف کسب‌وکار بدون پیش‌نیازهای بیرونی تأیید نشده‌اند. تست شبیه‌ساز معادل این آزمون‌ها معرفی نمی‌شود.
